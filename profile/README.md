## 🚀 Overview
OctaneRender for Windows is a GPU render engine from OTOY that installs as a plugin inside host 3D applications such as Cinema 4D and Blender. Instead of relying on your CPU, it uses your graphics card to compute light, materials, and reflections, so you see near-final quality in an interactive viewport while you work. It is built for artists who want photorealistic output without leaving the tools they already know, and it is also available as a standalone edition for opening and rendering supported scene files on their own.

## ✨ Features
- **GPU-accelerated rendering** — OctaneRender gpu rendering harnesses your graphics card for fast, physically based image computation.
- **Live interactive viewport** — Preview lighting, materials, and camera changes in near real time as you adjust your scene.
- **Physically based materials** — Build realistic surfaces with a spectral, energy-conserving material system.
- **Host application integration** — Works as a plugin inside 3D software like Cinema 4D and Blender, using your existing scene data.
- **Standalone edition included** — Open and render supported scene files in the standalone OctaneRender application when you prefer to work outside a host.

## 💻 System Requirements
| Component | Minimum | Recommended |
|-----------|---------|-------------|
| OS | Windows 10 64-bit | Windows 11 64-bit |
| Host application | A supported version of a host 3D app such as Cinema 4D or Blender | The latest supported release of your chosen host 3D application |
| Graphics | A CUDA-capable NVIDIA GPU that meets the engine's minimum | A modern high-VRAM NVIDIA GPU for larger, faster renders |
| Processor | A modern 64-bit multi-core processor | A recent multi-core desktop processor |
| Memory | 8 GB RAM | 16 GB RAM or more |
| Storage | A few GB of free space for the plugin and cache | An SSD with ample free space for scenes and cache |

## 📥 Installation
1. Click the **Download** button above to get the latest OctaneRender plugin package for your host application.
2. Run the downloaded installer, or add OctaneRender through your host application's plugin manager, following the on-screen setup steps.
3. Open your host 3D application, where OctaneRender appears in the render-settings and materials menus; activate your OTOY license or sign in to your OTOY account when prompted.

## 🎯 Getting Started
1. Open your host 3D application and load or create a scene.
2. Set OctaneRender as the active render engine in the render settings.
3. Open the live viewport to start interactive GPU rendering.
4. Assign OctaneRender materials and adjust lighting until the preview looks right.
5. Render the final frame or animation and export your image.

## ❓ FAQ
**Is OctaneRender free?**
OctaneRender is offered by OTOY through a subscription, with a free or limited tier available so you can try GPU rendering before committing. There is no free full copy of the paid tiers.

**Which versions of Windows are supported?**
OctaneRender runs on 64-bit Windows, with Windows 10 and Windows 11 recommended for the best experience.

**Is my data secure?**
Your scenes and rendered output stay on your own Windows machine unless you deliberately use a cloud service, so you keep control of your project files.
